# AIMalb

AI-ассистент для Wear OS с голосовым управлением.

Проект создан для умных часов на Wear OS 3.5 и выше. Ассистент позволяет отправлять голосовые запросы, получать ответы от ИИ и озвучивать результат прямо на часах.

## Возможности

* 🎙 Голосовой ввод запросов
* 🤖 Интеграция с AI-моделями через API
* 🔊 Озвучивание ответов (TTS)
* 🌐 Получение актуальной информации через поиск в интернете
* ⌚ Оптимизация интерфейса под маленький экран часов
* 📱 Companion-приложение для телефона (передача настроек и API-ключей)

## Технологии

* Kotlin
* Jetpack Compose
* Wear OS
* Android Data Layer API
* Retrofit
* Kotlin Coroutines
* Groq API
* SearXNG API

## Архитектура

Проект состоит из двух приложений:

* `wear` — основное приложение для часов
* `mobile` — приложение-компаньон для смартфона

Связь между устройствами выполняется через Wear OS Data Layer.

## Статус проекта

В разработке.

## Использование ИИ

При создании проекта использовались инструменты искусственного интеллекта для помощи в разработке, анализе кода и поиске решений.

Основной AI-инструмент, использованный в процессе разработки:

* Google Gemini — помощь с генерацией и анализом кода, архитектурными решениями и отладкой.

ИИ использовался как вспомогательный инструмент. Все решения, интеграция компонентов и финальная проверка кода выполнялись в процессе разработки проекта.
